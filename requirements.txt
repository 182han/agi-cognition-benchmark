# C2A / C9 提交包 · 依赖清单
#
# 本包**只依赖 Python 标准库**（>= 3.7；实测 3.9.6 / macOS arm64）。
# 下面把「本来可以用但刻意不用」的依赖也列出来并说明原因，方便评审核对。
#
# === 实际需要 ===
# （无。pip install 什么都不用执行。）
#
# === 刻意不用的 ===
# pypdf            —— 只在**读挑战材料**时用过（抽取 DeepMind 摘要 PDF 的文本）。
#                     它不属于交付物的运行依赖：基准本身不读任何 PDF。
# openpyxl/pandas  —— 结果汇总用 markdown 表格即可，不引入表格库。
# numpy            —— 本包的计算量（规则搜索、指标计算）用纯 Python 完全够用；
#                     引入 numpy 只会给复现者增加安装失败面。
# pytest           —— tests/test_smoke.py 与 bench/selfcheck.py 都是纯标准库实现，
#                     直接 python3 运行并返回退出码，不需要测试框架。
#
# === 运行环境要求 ===
# Python >= 3.7
# 磁盘：< 20 MB（数据集 + 结果）
# 内存：< 200 MB
# GPU：不需要
# 网络：不需要（唯一需要网络的路径是显式接入前沿模型 API，见 README「已知缺口」）
